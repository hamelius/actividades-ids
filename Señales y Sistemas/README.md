# Análisis de Señales y Sistemas con la Transformada de Fourier

Este repositorio contiene la implementación práctica para el análisis de señales en el dominio del tiempo y de la frecuencia utilizando Python (NumPy y Matplotlib).

## Contenido del Proyecto
1. **Generación de Señales:** Creación de funciones senoidales compuestas y pulsos rectangulares.
2. **Aplicación de FFT:** Transformación numérica al dominio de la frecuencia mediante `np.fft.fft`.
3. **Análisis Espectral:** Interpretación gráfica de los picos de frecuencia y envolventes espectrales.
